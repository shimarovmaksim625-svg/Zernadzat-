# Кофейня «Зёрнышко»

Учебный сайт кофейни с описанием заведения, меню, бронированием столиков и контактной информацией.

## Страницы сайта

Все страницы находятся в папке `tamplates/`:

- `index.html` — главная: преимущества кофейни, популярные блюда и примеры отзывов.
- `menu.html` — меню с описаниями и ценами; позиции можно отфильтровать по категориям.
- `about.html` — история кофейни, атмосфера, команда и ценности.
- `booking.html` — форма бронирования с проверкой введённых данных. Отправка демонстрационная: данные не передаются на сервер.
- `contacts.html` — адрес, телефон, часы работы и виджет Яндекс Карт.

## Запуск

Откройте `tamplates/index.html` в браузере. Для проверки локальных ссылок и ресурсов можно запустить проект через любой локальный статический HTTP-сервер.

## Структура проекта

- `tamplates/` — HTML-страницы.
- `styles/styles.css` — основные стили.
- `styles/responsive.css` — адаптация для мобильных экранов.
- `js/script.js` — мобильная навигация, фильтр меню и демонстрационная обработка формы.

## Содержание

В меню представлены кофе, чай, десерты и завтраки. Главная показывает три популярные позиции; их цены соответствуют полному меню. Тексты отзывов на главной являются примерами, а не реальными отзывами гостей.

Адрес «г. Москва, ул. Примерная, 12» и контактные данные демонстрационные. Перед публикацией замените их на подтверждённые данные кофейни; расположение виджета карты зависит от поиска этого адреса в Яндекс Картах.
